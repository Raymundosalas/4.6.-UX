# README - Helix Jump 3D Unity

## Descripción

Este proyecto consiste en un videojuego 3D estilo Helix Jump desarrollado en Unity para Android. Se implementaron mejoras visuales y mecánicas para enriquecer la experiencia del usuario, incluyendo modo Super Speed, barra de progreso, sistema de puntuación, partículas y pantalla de Game Over.

---

## Funcionalidades implementadas

* Movimiento y rebote de la pelota.
* Rotación de plataformas.
* Sistema de puntuación.
* Barra de progreso con Slider UI.
* Efecto Super Speed.
* Partículas visuales.
* Cámara dinámica.
* Pantalla de Game Over.
* Reinicio automático del nivel.

---

## Tecnologías utilizadas

* Unity 3D
* C#
* TextMeshPro
* UI Slider
* Particle System

---

## Scripts incluidos

* `BallController.cs`
* `GameManager.cs`
* `ProgressBar.cs`
* `ScoreUI.cs`
* `RotatePlatform.cs`
* `GameOverUI.cs`
* `SuperSpeedEffect.cs`

---

## Resultado

El videojuego ahora cuenta con efectos visuales y mecánicas más dinámicas que mejoran la jugabilidad y ofrecen una experiencia más atractiva para el usuario en dispositivos Android.
